u2af1-CSC

Repository of scripts & analysis used for analysis for U2AF1 CSC project.

Description of contents:

- DESeq2 R commands used to perform differential gene expression analysis of HBECs with U2AF1 and mutation and cigarette smoke treatment (CSC). All mutant cell lines were compared to the control, U2AF1 WT + DMSO genotype.

- Script used to filter gene expression results from DESeq2 and produce an input file for Gene Set Enrichment Analysis (GSEA) Preranked analysis. Then, takes GSEA output and plots heat maps of enrichment scores for significantly enriched pathways.
